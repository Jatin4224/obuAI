# Design References

Drop your UI mockups, screenshots, and design inspiration images here.

Claude will reference this folder when making UI decisions for Bulky AI.

## What to put here
- Screen mockups (PNG/JPG)
- Figma exports
- Inspiration screenshots from other apps
- Color palette swatches
- Typography samples

## Naming convention
- `home-screen.png`
- `onboarding-step1.png`
- `paywall.png`
- `foods-screen.png`
- `progress-screen.png`
- `profile-screen.png`
- `inspiration-*.png`
